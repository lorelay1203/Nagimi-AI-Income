# RESEARCH & TRENDS

## Propósito
Usar investigación continua para decidir qué crear.

## Temas a monitorear
- Nuevas herramientas de IA.
- Agentes de IA.
- Automatización para pequeñas empresas.
- Micro-SaaS.
- Creator economy.
- Cambios en monetización de YouTube/TikTok/Instagram.
- Negocios digitales emergentes.
- Modelos de afiliación.
- Tendencias en IA aplicada a finanzas.

## Método
Cada oportunidad se debe guardar con:
- Fecha.
- Qué está creciendo.
- Evidencia.
- Competencia.
- Cómo monetiza.
- Tiempo estimado a ingresos.
- Nivel de automatización.
- Decisión: PROBAR / OBSERVAR / DESCARTAR.
