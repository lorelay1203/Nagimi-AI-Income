# NAGIMI AI INCOME

Negocios creados con AI para generar contenido y generar ingresos online, de forma automatizada.

Esta carpeta es el centro de organización para todos los proyectos bajo la marca NAGIMI AI.

## Estructura

- `00_MASTER` — contexto, decisiones y dirección general.
- `01_NAGIMI_AI_SAAS` — producto principal de largo plazo.
- `02_AI_INCOME_CASHFLOW` — proyectos para generar efectivo.
- `03_CONTENT_FACTORY` — canales y automatización de contenido.
- `04_RESEARCH_TRENDS` — oportunidades y tendencias.
- `05_BRAND_MARKETING` — marca, mensajes y estrategia.
- `06_AUTOMATIONS` — flujos automatizados.
- `07_FINANCE_REINVESTMENT` — reglas para reinvertir ingresos.
- `99_PARKING_LOT` — ideas que no se ejecutarán todavía.

## Cómo usarla

Antes de abrir un nuevo negocio o canal:
1. Crear una subcarpeta dentro del área correspondiente.
2. Añadir un `README.md` con objetivo, monetización, estado y próximo paso.
3. Mantener el contexto importante en Markdown.
4. Actualizar `00_MASTER/MASTER_CONTEXT.md` cuando haya una decisión estratégica importante.
